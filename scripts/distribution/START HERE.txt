BIG WALK COMPANION v0.3.1 - WINDOWS

1. Extract the entire ZIP into a writable folder. Do not run inside the ZIP.
2. Close Big Walk and double-click Install.cmd.
3. Choose Enter for a normal installation, or M if you launch through a mod
   manager. For M, open the active profile folder in your manager and paste
   that folder path (or its BepInEx folder). The choice is remembered.
4. A normal install locates Steam, installs the loader and plugin, then launches
   Big Walk and the companion. For a managed profile, launch MODDED through
   the manager yourself; the installer opens the companion using that profile.
   Join a world. The first modded launch can take
   several minutes. The companion runs in the background; no command window
   needs to stay open.

The calibrated map image is included in the mod and companion package.
You do not need to finish the starting area, have a progressed save, or open
the in-game map. The PNG encoding code that caused the crash is removed.
Existing BepInEx/companion/map.png files are preserved; the bundled image
also works immediately when the game is not running.
For later sessions, just launch the game. The mod starts the companion and
opens its browser page automatically. Start Companion.cmd also opens it
manually; Stop Companion.cmd stops the background server. The server stays
available after you quit the game so you can review notes and recordings.
Keep this extracted folder in place. If you move it, run Install.cmd again
to update the mod's launch registration.
To disable automatic startup, close the game and set AutoStart = false under
[Companion] in BepInEx/config/com.jonpot.bigwalk.companion.cfg.
No Node.js or .NET SDK installation is needed.
Launchers prefer PowerShell 7 (pwsh.exe) and fall back to Windows PowerShell.

Full-screen notes include a zoomed-in minimap in the bottom-left corner,
following the selected player with nearby POIs, routes, players and trains.

PLANNING AND SHARING
The Route planner panel is on the right. + POI places a named, categorized,
colored pin with notes. Change icon opens a searchable grid of all 1,848
bundled Lucide icons (works offline). Draw route lets you click out a path; Finish path
opens its name, color, notes and ordered steps. Link steps to POIs to show
their numbered markers. Save plan commits your work.
To edit, click a saved pin/path or its list entry. Adjust path lets you drag
vertices, click segments to insert, click the map to extend, and right-click
vertices to remove. Undo/redo and browser-local draft recovery are included.
Search and category filters help find POIs; layer toggles hide POIs/routes.
Export pack shares all saved pins, paths, steps, notes, images and alignment.
Import pack offers Add (independent copies, keeps your alignment) or Replace.
New packs require v0.3.1 or newer; old area-only packs can still be imported.
Run mode follows your player and advances linked POI steps after arrival and departure.
The checklist and timer stay in your browser and are not included in exports.
The previous saved pack is kept in data/route-pack.previous.json.
This release retains the working v0.1.3 game plugin; the planner is part of
companion v0.3.1. Starting this package updates the matching background server.
Refresh already-open companion pages after starting the new package.

MOD MANAGERS
Install the BepInEx 6 IL2CPP x64 package in the selected profile first. The
companion installs only its plugin into that profile; it does not replace
the manager's loader or launch the game outside the manager.
Start Companion.cmd remembers the profile for map, positions, and recordings.
To switch profiles, run Install again and choose M. To return to a normal
game-folder installation, choose D. The installer prints both selected paths.
Advanced: Install.cmd -GamePath "C:\...\Big Walk" -BepInExPath "C:\...\profile"
Use -UseGameFolder instead of -BepInExPath to select the normal installation.

Select the player whose area notes you want to follow. Draw an area, write
notes, and use the bounds editor to move or resize it. Images can be pasted
or uploaded in the Markdown editor. Export/Import transfers notes and images.
Each player runs a local companion; live shared notes are not included.

UPDATING AND DATA
Keep your data folder, or export notes before replacing a release. Notes and
images are in data/route-pack.json. Existing loader settings are preserved.
Replaced companion DLLs are backed up in backups/. Recordings are under the
selected BepInEx/companion and are not automatically pruned. Delete unwanted
session-*.jsonl files with the game closed.

TROUBLESHOOTING
- No positions: join a world and inspect LogOutput.log inside the selected
  BepInEx folder for Big Walk Companion. For a managed profile, launch modded.
- Loader conflict: existing unrecognized loader files are not overwritten.
  Matching files from the bundled loader can be kept while missing files are
  installed. A different winhttp.dll alone does not prove BepInEx is absent:
  it may belong to a manager or another loader. Do not delete it blindly.
  The error shows the game folder checked and the expected BepInEx DLL.
  Use BepInEx 6 Unity IL2CPP Windows x64 (not Mono or BepInEx 5).
  Build: https://builds.bepinex.dev/projects/bepinex_be
  Setup: https://docs.bepinex.dev/master/articles/user_guide/installation/unity_il2cpp.html
  Included tested version: 6.0.0-be.788+5b766a3.
- Access denied: run Install.cmd as administrator if the game folder requires
  it. Normal companion use does not require administrator access.
- Wrong folder: delete game-path.txt beside this file and start again.
- Missing/moved profile: run Install again and select the current profile.
- Browser did not open: inspect data/launcher.log and data/server.log beside
  the companion. If another copy/profile is running, stop that copy first.
  Startup errors are also logged in BepInEx/LogOutput.log and do not stop play.
- Removal: close the game and delete only the game folder's
  BepInEx/plugins/BigWalk.Companion/BigWalk.Companion.dll.

Game updates may require a new plugin build. Map artwork is by House House.
Third-party runtime notices are in licenses/.
Source and updates: https://github.com/Jonpot/big-walk-companion

CRASHES AND DIAGNOSTICS
Before relaunching after a crash, double-click Collect Diagnostics.cmd.
It creates a ZIP under diagnostics/ with existing Unity/BepInEx logs, the
latest position snapshot, plugin inventory, and available crash text logs.
No upload occurs. Review the ZIP and send it privately with the crash time,
time zone, what you were doing, and the mod manager/profile used.
Logs can contain player names and local paths. Notes, saves, artwork, and
full session recordings are excluded. Missing logs are listed in README.txt.
Optional: Collect Diagnostics.cmd -IncludeCrashDumps includes available .dmp
files (up to 100 MB each, 200 MB total collected files). Dumps can contain
process memory. Oversized or unreadable files are listed, not collected.
For an older install, -BepInExPath "C:\...\profile" selects managed logs.

Manual collection:
  %USERPROFILE%\AppData\LocalLow\House House\Big Walk\Player.log
  %USERPROFILE%\AppData\LocalLow\House House\Big Walk\Player-prev.log
  The newest bigwalk-*.log files in the same folder
  <selected BepInEx folder>\LogOutput.log
  ErrorLog.log in the game folder or selected BepInEx folder (if present)
  %TMP%\House House\Big Walk\Crashes (if present)
The companion records telemetry, not native crash dumps. Unity may produce
crash reports, but not every crash creates one. Relaunching can rotate logs.
If logs were redirected, use -UnityLogPath or -CrashPath with the actual folder.

HANDS-FREE RUN MODE
Choose a route and player, then Start timer. The map follows the runner and
highlights the path to the next POI. A direction arrow and current instructions
stay above full-screen notes. Arrive within 12 world units for half a second;
instructions remain until you leave 18 units, then the next step takes over.
Adjust the arrival radius before starting if needed (exit uses 1.5 times it).
Completed steps hide; long instructions page automatically. The timer stops
after leaving the last POI. Replay or stale telemetry cannot advance a run.
Puzzle completion itself is not detected; this tracks arrival and departure.
