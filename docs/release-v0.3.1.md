# Big Walk Companion v0.3.1 — Dismissible notifications

Save confirmations automatically disappear after six seconds. All notifications now include a close button, so they cannot remain stuck over the companion. Error messages remain until dismissed or replaced.

Includes all v0.3.0 hands-free route features. Saved routes and notes are unchanged. Download the complete Windows ZIP, extract it, close the game and run Install.cmd using your existing notes directory. Save any open edits before refreshing the companion page.

Validated automatic dismissal, manual dismissal, planner interactions, and package integrity/runtime checks.
